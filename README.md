# Portfolio League of Legends — Zachary Arnaud

Ce projet transforme l'interface officielle de présentation de champion de **League of Legends** en un **portfolio interactif et immersif** pour **Zachary Arnaud** (Marketing & Business Development — Gaming & Esport).

---

## 🚀 Comment lancer et tester le portfolio ?

Double-cliquez simplement sur le fichier **[`index.html`](file:///C:/Users/utilisateur/.gemini/antigravity/scratch/lol-caitlyn-page/index.html)** pour l'ouvrir dans n'importe quel navigateur (Chrome, Edge, Firefox, Brave, Safari, etc.).

---

## 📁 Architecture du projet

```text
lol-caitlyn-page/
├── index.html          # Structure de la page (Vue d'ensemble, Compétences, Expériences, Footer)
├── style.css           # Thème visuel LoL (oblique, tracker vertical, barres cyan, design 2019-2023)
├── champion-data.js    # VOS DONNÉES PERSONNELLES (Textes, compétences, expériences, liens)
├── script.js           # Moteur interactif (gestion des onglets de sorts et carrousel d'expériences)
└── README.md           # Ce guide
```

## ✏️ Comment personnaliser vos informations ?

Toutes vos données sont réunies dans **[`champion-data.js`](file:///C:/Users/utilisateur/.gemini/antigravity/scratch/lol-caitlyn-page/champion-data.js)**. 

Pour modifier vos coordonnées, ajuster la description d'une expérience, ou remplacer une image par une capture de vos projets ou votre photo de profil:
- Ouvrez `champion-data.js` dans votre éditeur.
- Modifiez les textes ou remplacez les URLs des images (`splash`) par vos propres fichiers locaux ou liens.
